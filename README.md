# Análise Global de Vendas e Logística

## Visão Geral
Este projeto analisa dados globais de vendas e logística para identificar insights de negócio, padrões de vendas, gargalos operacionais e oportunidades de otimização.

A análise foi realizada utilizando Python com foco em limpeza de dados, análise exploratória (EDA), desempenho logístico e comportamento de vendas entre países e produtos.

---

## Objetivos
- Analisar o desempenho de vendas por regiões e produtos
- Identificar padrões logísticos e de envio
- Detectar ineficiências operacionais
- Gerar insights de negócio através de análise exploratória

---

## Análise Exploratória de Dados
Principais análises realizadas:
- Distribuição de vendas

## Principais Insights
- Identificação de regiões com maior concentração de vendas
